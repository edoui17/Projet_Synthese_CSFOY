## 2024-05-25 - Error Dialog Keyboard Focus & Juice
**Learning:** For static Control nodes loaded during `_Ready` like `m_retryBtn` and `m_offlineBtn` inside a CanvasLayer popup, focus navigation needs to be explicitly wrapped for keyboard users so they aren't trapped if focus falls out of bounds (e.g. `FocusNeighborRight/Left`). Additionally, when using `.CreateTween()` to scale buttons for Game Juice, `PivotOffset = btn.Size / 2f` must be set immediately before the tween executes to ensure it scales cleanly from the center rather than the top-left origin.
**Action:** Always setup cyclic `FocusNeighbor` arrays/paths for distinct popup choice buttons, and update `PivotOffset` immediately on `FocusEntered` prior to animating `.scale`.

**Action:** Always setup cyclic `FocusNeighbor` arrays/paths for distinct popup choice buttons, update `PivotOffset` immediately on `FocusEntered` prior to animating `.scale`, and manage active tweens by killing them before creating a new one.
