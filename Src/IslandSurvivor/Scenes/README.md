# Scenes

Ce dossier regroupe tous les fichiers de scènes Godot (`.tscn`). C'est ici que le jeu prend vie visuellement.

### Organisation :
* `/Levels` : Les scènes principales représentant les niveaux du jeu.
* `/UI` : Menus, barres de vie, et inventaires.
* `/Entities` : Les objets préfabriqués (Joueur, Ennemis, Items) qui sont instanciés dans les niveaux.

**Note :** Chaque scène devrait, dans la mesure du possible, avoir son propre script attaché portant le même nom pour faciliter la navigation.
