# Assets

Ce dossier contient toutes les ressources brutes (non-code) utilisées par le moteur Godot. 

### Structure suggérée :
* `/Audio` : Musiques (.ogg) et effets sonores (.wav).
* `/Sprites` : Images 2D, textures et feuilles de sprites (spritesheets).
* `/Fonts` : Polices de caractères (.ttf, .otf).
* `/Themes` : Ressources pour l'interface utilisateur (UI).

> **Règle d'or :** Aucun fichier de script (.cs) ne doit se trouver ici. Ce dossier est réservé aux données visuelles et sonores.
