# Infrastructure (Accès aux données)

Ce projet gère la persistence des données avec **Entity Framework Core (EF Core)**.

### Contenu :
* **Data/** : Le `AppDbContext` qui fait le lien avec SQL Server.
* **Migrations/** : L'historique des versions de la base de données.
* **Repositories/** : Implémentation des accès SQL.

### Technologies :
* SQL Server / SQLite.
* EF Core.
